HERITAGECONNECT - EASY DBMS DEMO

YOUR TWO MODULES
1. Bilingual Guide, Translator & Security Escort Booking + Verification
2. Partner Ads / Featured & Discount Section

TECHNOLOGY
PHP + MySQL + HTML + CSS
Run with XAMPP.

SETUP
1. Install XAMPP.
2. Start Apache and MySQL.
3. Put the folder "DBMS_Project" inside:
   C:\xampp\htdocs\
4. Open:
   http://localhost/phpmyadmin
5. Create/import database.sql.
6. Open:
   http://localhost/DBMS_Project/

DEMO FLOW
A. Homepage
- Search Guide / Translator / Security Escort.
- Search by language.
- Only verified providers are shown.
- Click Book Now.
- Choose date and time.
- Confirm booking.
- Open My Bookings.

B. Admin
Open:
http://localhost/DBMS_Project/admin/

- Verify a pending provider.
- Confirm or cancel bookings.
- Add a new Partner.
- Add a new Advertisement.
- Delete Partner or Advertisement.

C. Partner section
Homepage shows:
- Featured partners
- Discount percentage
- Current advertisements

IMPORTANT
The hotel, restaurant and tour company names in database.sql are DEMO DATA.
You can delete them and add your own from Admin.

PRESENTATION LINE
"My contribution is the service-provider booking and verification module and the partner advertisement, featured and discount module. Users can search verified services, make bookings, and view partner offers. Admin can verify providers, manage bookings, add partners and publish advertisements."
