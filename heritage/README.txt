HeritageConnect DBMS Project

PHP + MySQL + HTML + CSS project for XAMPP.

Setup:
1. Start Apache and MySQL in XAMPP.
2. Put this folder inside C:\xampp\htdocs\.
3. Open phpMyAdmin and import database.sql.
4. Open http://localhost/HeritageConnect/

Website includes guides, translators, security escorts, booking, partner offers and advertisements.
The admin area is protected by the admin login.
